# Bozze dungeon

Conserva qui i file `*.draft.json` esportati dal dungeon maker.

Per installare una bozza: `npm run dungeon:import -- content/dungeons/nome.draft.json`, quindi `npm run build` e riavvia il server.

I contenuti effettivamente caricati dal gioco sono in `shared/custom-dungeons.json`. Vedi [guida dungeon maker](../../docs/dungeon-maker.md).
